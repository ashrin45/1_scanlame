# Scan lame

Capture de champs microscopiques a intervalle regulier depuis un smartphone pose sur l'oculaire,
avec suivi de position en direct et carte de couverture. Les photos sont assemblees ensuite en lame virtuelle.

Ouvrir sur le telephone (Chrome Android) : https://ashrin45.github.io/1_scanlame/

Usage : Demarrer la camera, mise au point a la bague du microscope, verrouiller AF/AE, lancer la serie,
deplacer la platine lentement en serpentin, arreter, telecharger le ZIP (photos + serie.json avec les positions).
